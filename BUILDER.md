# Our builder

One command builds one phone agent from a bank brief and its tool API file:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp env.example env.sh   # FREYA_API_KEY (and a team key); Claude login or ANTHROPIC_API_KEY for the builder model
source env.sh

python3 builder/build.py {brief_path} {tool_api_path} 2>&1 | tee traces/<name>.log
# a brief that builds on an earlier one: pass both, base first
python3 builder/build.py briefs/base.md briefs/extension.md tools.openapi.json
```

Output: `submission/<slot>.workflow.json` (exported with `freya.export_workflow`), `traces/<slot>-<time>.log`
(start/end, every model call, what was created on Freya, every test result). Work files go to `out/` (git-ignored).

## How it works

```
brief + tool API  --(Claude, skill builder/skill/SKILL.md)-->  out/<slot>.spec.json   (every brief-specific value)
spec              --(builder/lib/collections_gen.py, plain code)-->  workflow JSON
workflow          --(builder/lib/check.py, localrun.py)-->  static checks + code nodes run locally on test dates
                  --> freya.save_workflow -> smoke chat test -> export to submission/
```

- The model only reads the brief and fills the spec. The workflow is generated by code, so structure, tools,
  hooks and routing are the same in every build.
- Dates, deadlines, floors, attempt offers and the callback window are computed in code nodes at call time from `now`.
- `check_date`: a code tool the phone agent calls for any date the customer names; the code answers (past, after the
  deadline, non-business day with the next/previous business day, or valid) and the agent answers in the same turn.
- Every bank tool result carries a `what_to_do_next` line (post hooks); failure instructions are also in the tool
  descriptions, because a failed HTTP call never reaches the hook.
- `builder/lib/check.py` checks structure, Python of every code node and hook, tool fields against the tool API,
  variables, the spec against the brief, and that no sentence was copied from material the builder must not reuse.

Nothing from any hidden brief is in this repository. `builder/examples/` holds a made-up bank (shape only);
`builder/devtests/` holds our spec for the public Brief A, used only by our own tests (the builder is told not to open it).
